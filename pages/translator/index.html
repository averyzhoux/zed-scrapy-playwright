zed-sp-translate

翻译器子包：把 scrapy-playwright 风格的写法翻译成 zsp 的执行流程。

v0.1.0dev1 导入名 zed_sp_translate 可选安装

它面向从 scrapy-playwright 迁移过来的项目：旧代码里常见的 meta（例如 playwright_page_methods）会被翻译成 等价的 zsp 执行步骤，从而复用主包的 Provider。

开发中 · 预留位置 目前该子包只有占位实现：Translator 是一个空类， translate.py 中的翻译逻辑仍以注释形式存在，尚未启用。

安装

pip install "zed-scrapy-playwright[translate]"
# 或
pip install zed-sp-translate

API（占位）

from zed_sp_translate import Translator

# 预留：按旧写法生成/翻译执行步骤
translator = Translator()
成员状态说明
Translator占位子包对外导出的翻译器类。
zed-sp-translate占位控制台脚本入口，目前仅打印欢迎信息。

规划中的能力

根据子包内的注释草稿，翻译器计划承担以下工作：

  • 识别兼容请求，并从 Provider 取用页面（provider.css()）。
  • 把 meta["playwright_page_methods"] 逐条应用到页面上。
  • 可选的 Stealth 反检测注入。
  • 把页面源码包装成 HtmlResponse 返回给 Scrapy。
# 旧写法（scrapy-playwright）
meta = {
    "playwright_page_methods": [
        PageMethod("wait_for_selector", "h1"),
    ],
}
