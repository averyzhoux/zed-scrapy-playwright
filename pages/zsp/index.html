zed-scrapy-playwright

导入名 zed_scrapy_playwright（约定别名 zsp）。

v0.3.1dev2 必装主包 MIT

主包提供 Scrapy 下载器中间件与一套请求 / 响应类型。它拦截标记过的 ZedRequest，把执行权交给一个 Playwright Provider，并把执行结果包装成普通的 Scrapy Response 交回引擎。

公共 API

名称说明
zsp.enable(config=None) 类装饰器：挂载 Spider.config，并包装 Spider.start 以便启动时自检。
zsp.validate(spider) 检查中间件是否已注册到 DOWNLOADER_MIDDLEWARES，返回布尔值。
zsp.ZedRequest(...) 继承自 scrapy.Request，额外携带 execution 与 selector。
zsp.ZedResponse(result, ...) 继承自 scrapy.http.Response，执行结果放在 .result。
zsp.ExecParam(request, page) 执行函数入参，字段为 .request 与 .page。

ZedRequest 参数

参数类型说明
executionCallable异步执行函数，接收一个 ExecParam。
callbackCallableScrapy 回调，接收 ZedResponse 或 HtmlResponse。
selectorstr | None配合调度器子包使用的 CSS 选择器。
metadict | None透传给 Scrapy。
dont_filterbool默认 True。

执行契约

async def execution(ep: zsp.ExecParam) -> dict | None:
    await ep.page.goto(...)     # 同步风格书写异步操作
    return {"key": value}       # 返回 dict → ZedResponse.result

# 返回 None 时，主包会用页面源码构造 HtmlResponse
请求前缀 ZedRequest 的 URL 被固定为 playwright://request， 响应为 playwright://response；中间件会拦截并改写这类内部请求。

配置

{
    "browser_type": "chrome",
    "chrome_params": {
        "headless": False,
        "executable_path": "/opt/google/chrome/chrome",
    },
}

ConfigDict 的 chrome_params 对应 ChromeBrowserLaunchParameters，字段与 Playwright 的 chromium.launch() 参数一致（如 args、 timeout、proxy、slow_mo 等）。

工作流程

  1. @zsp.enable(config) 把配置挂到爬虫类，并在 start 前做自检。
  2. 中间件的 from_crawler 连接 spider_opened / spider_closed 信号。
  3. spider_opened 时创建 Provider：装有 zed_sp_schedule 时用 Scheduler，否则用 default.Provider，并调用 start()。
  4. 每个 ZedRequest 进入 process_request，交给 provider.takeover(request) 执行并返回 Response。
  5. spider_closed 时调用 provider.close() 释放浏览器资源。

模块构成

src/zed_scrapy_playwright/ ├── __init__.py # 导出 ExecParam / ZedRequest / ZedResponse / enable / validate ├── definition.py # ZedRequest、ZedResponse、ExecParam、Exection ├── functions.py # enable() 装饰器、validate() ├── handler.py # PlaywrightDownloaderMiddleware（下载器中间件） ├── interface.py # Provider 抽象基类、ConfigDict、ChromeBrowserLaunchParameters ├── default.py # 默认 Provider 实现（启动 / 关闭 / takeover） ├── constants.py # 包名、请求前缀、中间件路径 └── example.py # 示例爬虫 ExampleExecutor
模块职责
definition.py请求 / 响应 / 执行参数的数据定义。
interface.py定义 Provider 抽象基类，规定 start / close / takeover。
default.py不依赖调度器时的默认 Provider，直接新建页面并执行。
handler.py下载器中间件本体；解析 dev / extra 命令行参数并探测可选子包。
functions.pyenable() 与 validate()。
constants.py包名、请求前缀、中间件路径等常量。

可选扩展

  • zed-sp-schedule：安装后 spider_opened 会自动改用调度器 Provider，可用 CSS 选择器复用页面。
  • zed-sp-translate：把 scrapy-playwright 风格的 meta 翻译为 zsp 执行流程（开发中）。
