zsp

Less meta config, more Python code. 把 Scrapy 变成 Playwright 的事件调度引擎。

主包 v0.3.1dev2 Python ≥ 3.12 MIT License

zed-scrapy-playwright（简称 zsp） 是一个 Scrapy 与 Playwright 的集成中间件，提供会话级控制、 线性编码与精准数据传输， 让你在 Scrapy 爬虫里以同步风格的 Python 代码使用浏览器自动化能力。

核心特性

会话级控制

单次 execution 内可多次 page.goto()，保持页面状态。

线性编码

告别 callback 地狱，用同步风格书写异步浏览器操作。

精准数据传输

直接在 Page 对象中提取数据，无需额外的解析步骤。

完整类型提示

内联类型注解，享受 IDE 补全与类型检查。

装饰器启用模式

使用 @zsp.enable()，支持任意爬虫类。

Stealth 反检测

自动注入 playwright-stealth，降低被识别为机器人的风险。

包的组成

本仓库是一个 uv workspace，主包必装，两个子包为可选扩展。

zed-scrapy-playwright

主包：下载器中间件、ZedRequest/ZedResponse、 Provider 接口与默认实现。

src/zed_scrapy_playwright · v0.3.1dev2

zed-sp-schedule

可选调度器：用 CSS 选择器挑选并复用 Playwright 对象。

packages/zed-sp-schedule · v0.1.3dev

zed-sp-translate

可选翻译器：把常见于 scrapy-playwright 的 meta 翻译为 zsp 执行流程。

packages/zed-sp-translate · v0.1.0dev1

快速开始

1. 安装

pip install zed-scrapy-playwright
playwright install   # 首次使用需安装浏览器驱动

需要子包时使用 extras：

pip install "zed-scrapy-playwright[all]"      # schedule + translate
pip install "zed-scrapy-playwright[schedule]"  # 仅调度器
pip install "zed-scrapy-playwright[translate]" # 仅翻译器

2. 启用中间件

# settings.py
DOWNLOADER_MIDDLEWARES = {
    "zed_scrapy_playwright.handler.PlaywrightDownloaderMiddleware": 543,
}

3. 编写爬虫

import scrapy
import zed_scrapy_playwright as zsp

@zsp.enable({
    "browser_type": "chrome",
    "chrome_params": {"headless": False, "executable_path": "/opt/google/chrome/chrome"},
})
class MySpider(scrapy.Spider):
    name = "my_spider"

    async def start(self):
        yield zsp.ZedRequest(
            selector="page.default",
            execution=self.execution,
            callback=self.parse,
        )

    @staticmethod
    async def execution(ep: zsp.ExecParam):
        await ep.page.goto("https://example.com")
        return {"title": await ep.page.title()}

    def parse(self, response: zsp.ZedResponse):
        print("parse:", response.result)
